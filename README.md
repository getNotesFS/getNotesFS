## 👨‍💻 About me

I'm Sebastián, a full-stack developer based in Spain, freelancing as **SM Dev**. I build web platforms,
desktop and mobile apps, and the real-time systems behind them.

- 🔭 Currently working on real-time video and communication platforms
- 🎓 Background in Interactive Media and Web Engineering
- ⚡ Open to freelance projects — [let's talk](mailto:contacto@sfmarmol.com)

## 🚀 What I build

- 🌐 **Web platforms** — from custom WordPress sites to full-stack applications
- 🖥️ **Desktop & mobile apps** — cross-platform, built to keep working offline
- 📡 **Real-time systems** — video calls, VoIP and live speech features
- 🤖 **AI integrations** — avatars, speech and computer vision

## 🧭 How I work

- **Clean code & SOLID**, with decisions documented
- **i18n from day one**
- **Ship fast, verify for real**
- **Security by default**
